Music Library API

REST API documentation for the Music Library prototype.

Download OpenAPI JSON

Albums

POST /api/albums
Create a new album. Required fields: title, artist, genre, year, tracks.
GET /api/albums
Get all albums.
GET /api/albums/:id
Get a single album.
PUT /api/albums/:id
Update an album.
DELETE /api/albums/:id
Delete an album.
